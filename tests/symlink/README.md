# UltraCopy Ver.0.7 シンボリックリンク自動試験

## 1. 目的

UltraCopy Ver.0.7のシンボリックリンク複製処理について、
基本動作・複雑なリンク構造・属性の比較を自動検証する。

この試験は現行バージョンの動作確認を目的とし、
製品ソースコードの変更は行わない。

## 2. 試験ファイル

| ファイル | 内容 |
|---|---|
| test_basic_symlinks.py | 基本的なシンボリックリンクの複製 |
| test_advanced_symlinks.py | 複雑なリンク構造の複製 |
| test_symlink_attributes.py | 所有者・グループ・モード・日時の比較 |
| run_symlink_tests.py | 上記3試験の一括実行 |

## 3. 実行方法

プロジェクトのルートディレクトリで次のコマンドを実行する。

    .venv/bin/python tests/symlink/run_symlink_tests.py

個別に実行する場合：

    .venv/bin/python tests/symlink/test_basic_symlinks.py

    .venv/bin/python tests/symlink/test_advanced_symlinks.py

    .venv/bin/python tests/symlink/test_symlink_attributes.py

## 4. 検証項目

### 4-1. 基本試験

- 相対パスのファイルリンク
- 絶対パスのファイルリンク
- 壊れたシンボリックリンク
- ディレクトリへのシンボリックリンク
- リンク先文字列の一致
- 通常ファイルの内容
- ディレクトリ内のファイル
- コピー履歴の記録

### 4-2. 高度な試験

- 複数段階のリンク連鎖
- 循環リンク
- 外部への相対リンク
- 外部への絶対リンク
- /dev/null へのリンク
- コピー先でのリンク解決
- リンク先データの読み取り
- 外部リンク先を勝手に複製しないこと
- コピー履歴の記録

### 4-3. 属性試験

- 所有者 UID
- グループ GID
- モード
- リンク先文字列
- MTime
- ATime
- コピー履歴の記録

## 6. 確認済みの動作

- シンボリックリンクをリンクとして複製する。
- リンク先をたどって実体をコピーする動作は行わない。
- リンク先文字列を維持する。
- 循環リンクを無限にたどらない。
- コピー先でもリンク連鎖を解決できる構成がある。
- 外部相対リンクは、参照先がコピーされなければコピー先で解決できない場合がある。
- コピー履歴が試験専用データベースに記録される。

## 7. 既知の制限事項・未検証事項

### 7-1. タイムスタンプ

Ver.0.7ではシンボリックリンク自身のMTimeは引き継がれない。

ATimeも一致しない。ATimeは読み取り操作などで変化するため、
今回の比較結果だけで保存性能を評価することはできない。

### 7-2. 所有者・グループ

今回の試験ではコピー元とコピー先のUID・GIDが一致した。

ただし、同じユーザーで実行した試験であるため、
異なる所有者・グループを持つリンクの属性保持は未検証。

### 7-3. モード

今回のLinux環境ではモードが0o777で一致した。

Linuxの一般的なファイルシステムでは、
シンボリックリンク自身の権限ビットは通常、実質的なアクセス制御に使用されない。

## 8. 試験データの保存場所

各試験は次のディレクトリ内に固有の作業場所を作成する。

    tests/symlink/runs/

各試験の作業場所には、コピー元・コピー先・試験専用データベースなどが保存される。

試験データは自動削除しない。

## 9. 注意事項

- この試験はUltraCopy Ver.0.7の現状確認を目的とする。
- 試験用データベースは各試験の作業場所に作成する。
- 通常利用するコピー履歴データベースは試験対象にしない。
- 試験作業場所は自動削除しない。
- 試験結果は実行環境とファイルシステムに依存する。
- PASSは試験で設定した条件における成功を意味し、
  あらゆる環境での完全な動作を保証するものではない。
